วิธีเปิดดู
1. เปิด index.html ด้วย Microsoft Edge หรือ Google Chrome
   ไฟล์นี้รวมโมเดล ตัวดู และภาพอ้างอิงไว้แล้ว ใช้งานออฟไลน์ได้
2. ลากเมาส์ซ้ายเพื่อหมุน / หมุนล้อเพื่อซูม / ลากเมาส์ขวาเพื่อเลื่อน
   บนจอสัมผัสใช้นิ้วหนึ่งนิ้วหมุน สองนิ้วเลื่อนหรือบีบเพื่อซูม
3. เลือกภาพรวม ชุดผลิต ผังด้านบน หรือระดับสายตาจากแถบซ้าย
4. เปิด–ปิดแต่ละหมวดได้ เช่น ซ่อนรั้วเพื่อดูเครื่องจักรภายใน
5. เปิด “ชื่อส่วนต่าง ๆ” แล้วคลิกป้ายเพื่ออ่านขนาดและที่มาของข้อมูล
6. ปุ่มมุมขวาบนใช้บันทึกภาพ PNG และเปิดเต็มหน้าจอ
7. กด R เพื่อกลับมุมมองภาพรวม

ไฟล์ที่ให้
- index.html : ตัวดูสามมิติแบบออฟไลน์ เปิดไฟล์เดียวได้
- Bangna_32_Plant.glb : โมเดลสามมิติพร้อมวัสดุและภาพป้ายฝังในไฟล์
  ใช้หน่วยเมตร แกน Y ขึ้น แกน X ตะวันออก แกน -Z ทิศเหนือ
  จุดมุมตะวันตกเฉียงใต้ของไซต์คือ (-30, 0, 35)
  นำเข้า Blender ผ่าน File > Import > glTF 2.0 หรือโปรแกรมที่รองรับ GLB
  ชิ้นส่วนแยกเป็นหมวดและชุดประกอบ มีชื่อวัสดุสำหรับแก้ไขต่อ
- Bangna_32_Preview.png : ภาพตัวอย่างที่เรนเดอร์จากโมเดลจริง

ข้อมูลที่ยึดตามแบบ
- พื้นที่ 60 × 70 เมตร รวม 4,200 ตารางเมตร
- เครื่อง CPC2.0 แบบ Star Type 1 ชุด
- ไซโล 180 ตัน จำนวน 3 ใบ
- ยอดราวกันตกไซโลระดับ +20.40 เมตร จากรูปตัดมาตรฐาน
- แผงกองวัสดุสูงสุด 7.20 เมตร: แผงริม 2 และแผงกลาง 3
  จัดเรียงแนวรัศมี เกิดพื้นที่กองวัสดุ 4 ช่อง
- ห้องควบคุม E และอาคาร DM, G ขนาด 3.00 × 8.40 เมตร
- ถังน้ำ F จำนวน 3 ถัง ถังละ 15,000 ลิตร
- H บ่อน้ำทิ้ง 5 × 12 เมตร
- I บ่อคายคอนกรีต 7 × 15 เมตร
- รั้วกันฝุ่นสูง 6 เมตร ทางเข้าด้านตะวันตก

   ลงวันที่ 17-12-55 ไม่ใช่รูปตัดเฉพาะโครงการฉบับตรวจรับ
   ใช้เป็นแนวทางรูปทรง ระดับสูงสุด และองค์ประกอบเครื่องจักร
3. SB01_B_Start.png_468981e9.jpg ใช้อ้างอิงสีฟ้า–แดง–ขาว วัสดุ
   ราวสีเหลือง รถ และบรรยากาศ ไม่ใช้เปลี่ยนผังหรือจำนวนอุปกรณ์
   ภาพอ้างอิงมีไซโล 4 ใบ แต่แบบโครงการมี 3 ใบ จึงสร้างตามแบบ 3 ใบ
4. PR.69-024_Bangna_32_01Nov2026.dwg ตรวจพบรูปแบบ AutoCAD 2007
   แต่เครื่องมือที่มีถอด geometry ไม่สมบูรณ์ ผลแปลงจึงไม่ใช้ในโมเดล
   ไม่ได้สรุปว่าไฟล์ต้นฉบับเสีย และไม่ได้ส่งแบบไปแปลงบนเว็บไซต์ภายนอก
5. เส้นผ่านศูนย์กลางไซโลประมาณ 3.70 เมตรจากสัดส่วนรูปตัด
   หน้าตัดเหล็ก ฐานรองรับ สกรูลำเลียง สคิป บูม เครื่องผสม ท่อ
   ข้อต่อ บันได ราวกันตก ประตู หน้าต่าง และระดับชานที่ไม่กำกับมิติ
   เป็นรูปทรงประมาณเพื่อให้ดูและตรวจภาพรวมได้

   ภายในห้องควบคุม รถ ต้นไม้ วัสดุในกอง และรายละเอียดในบ่อเป็นองค์ประกอบจำลอง
7. โมเดลไม่มีข้อมูลเหล็กเสริม ฐานรากใต้ดิน ระบบไฟฟ้า/ประปาครบวงจร
   หรือรายละเอียดผลิตเครื่องจักร เนื่องจากชุดแบบไม่ได้ระบุไว้

สถานะงาน
เป็นโมเดลสามมิติเพื่อดูภาพรวมและสำรวจรายละเอียดภายนอก พร้อมเปิดเผยข้อสมมติ
ยังไม่ใช่โมเดล BIM / shop drawing / as-built ที่ตรวจสอบขนาดทุกชิ้นส่วนแล้ว
หากต้องการความครบถ้วนระดับก่อสร้าง จำเป็นต้องมีแบบโครงสร้าง ฐานราก
แบบเครื่องจักรและระบบ พร้อมมิติและระดับที่ยืนยันสำหรับโครงการนี้

การตรวจสอบ
เปิดทดสอบไฟล์ HTML ใน Edge ทดสอบการหมุน ซูม เปลี่ยนมุมมอง ซ่อนหมวด
เปิดมิติและป้ายข้อมูล และส่งออก GLB โดยไม่เรียกไฟล์ภายนอก
GLB ตรวจด้วย glTF Validator เพิ่มเติมก่อนส่งมอบ
